# T.S. Serviceleistungen – Homepage

Eigenständige statische Website für T.S. Serviceleistungen.

## Seiten
- Startseite
- Fahrzeugpflege
- Gartenservice
- Drohnenfotografie
- Digitale Lösungen
- Kontakt
- Impressum und Datenschutz (vor Veröffentlichung mit vollständigen Angaben ergänzen)

## Anfrageformular
Die Anfrage-Buttons verweisen auf https://ts-serviceleistungen.github.io/termin-ts-serviceleistungen/

## GitHub Pages aktivieren
Die Website wird über GitHub Actions veröffentlicht. Falls der Workflow mit „Get Pages site failed“ abbricht, muss Pages einmal in den Repository-Einstellungen aktiviert werden:
1. Öffne **Settings → Pages**.
2. Unter **Build and deployment** als **Source** „GitHub Actions“ auswählen.
3. Danach unter **Actions** den Workflow „Deploy static website to GitHub Pages“ erneut starten oder einen Commit pushen.

## Vor dem Livegang prüfen
- Das originale Logo durch die endgültige freigestellte Logodatei ersetzen.
- Vollständige und rechtlich geprüfte Impressums- und Datenschutzangaben ergänzen.
- Externe Bildquellen und Google Fonts prüfen bzw. datenschutzkonform einbinden.
- Darstellung und alle Links auf Desktop und Mobilgerät testen.
